## Демонстрация сайтов

Рабочие браузерные приложения есть в ПР3, ПР4, ПР5 и ПР6. Для показа ПР5 запускается сайт и отдельный REST API; для ПР6 — браузерный CRUD-клиент и API. ПР1 и ПР2 состоят из JavaScript-скриптов и консольных результатов, отдельный сайт в этих заданиях не требуется.

| Работа | Команда запуска из папки практики | Адрес в браузере |
|---|---|---|
| ПР3 | `npm start` | `http://127.0.0.1:5503/` |
| ПР4 | `npm start` | `http://127.0.0.1:5504/` |
| ПР5 | `npm start` | `http://127.0.0.1:5507/` |
| ПР6 | `npm start` | `http://127.0.0.1:5506/` |

Для ПР5 и ПР6 используется API-порт 5505. Не запускайте эти две практики одновременно на стандартных портах.

## Быстрый запуск

Каждая практика запускается отдельно из своей папки. Для ПР4:

```bash
cd practice-04
npm test
npm start
```

Для ПР5 откройте `http://127.0.0.1:5507/` после `npm start`. Дополнительные команды в другом терминале: `npm run example:order`, `npm run example:fetch`, `npm run client` и `npm test`. Интерактивный пример event loop: `http://127.0.0.1:5507/examples/event-loop.html`.

Для ПР6:

```bash
cd practice-06
npm test
npm start
```

ПР5 и ПР6 используют по умолчанию API-порт 5505; их API-серверы не запускаются одновременно на одном порту.
