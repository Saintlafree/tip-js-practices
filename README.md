## Быстрый запуск

Каждая практика запускается отдельно из своей папки. Для ПР4:

```bash
cd practice-04
npm test
npm start
```

Для ПР5:

```bash
cd practice-05
npm start
```

Во втором терминале ПР5 можно запускать `npm run example:order`, `npm run example:fetch`, `npm run client` и `npm test`.

Для ПР6:

```bash
cd practice-06
npm test
npm start
```

ПР5 и ПР6 используют по умолчанию API-порт 5505; их API-серверы не запускаются одновременно на одном порту.
